# Tiệm Sợi Chỉ

Trang cửa hàng handmade minh họa, xây dựng bằng HTML, CSS và JavaScript thuần. Giao diện tham khảo tinh thần trình bày sản phẩm của website Cây Kim Sợi Chỉ nhưng sử dụng nội dung, hình minh họa và nhận diện riêng.

## Tính năng demo

- Tìm kiếm có gợi ý và không phân biệt dấu tiếng Việt.
- Lọc sản phẩm theo danh mục, size, chất liệu và màu sắc.
- Xem thông tin chi tiết, size và tình trạng hàng.
- Thêm, xem, xóa sản phẩm trong giỏ; nhập thông tin người nhận và tạo mã đơn.
- Mô phỏng thanh toán thành công/thất bại qua VietQR, VNPay và MoMo.
- Đơn hàng chỉ tồn tại trong phiên trình duyệt; không kết nối backend, vận chuyển hay cổng thanh toán thật.

## Mở trang

Mở `index.html` trong trình duyệt. Các hình minh họa SVG nằm trong thư mục `images`.
